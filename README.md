# AutoFillGeoPoints
Automatic Filling GeoPoints folder and xml files

# ДЛЯ ПРОГРАММЫ ПОНАДОБИТСЯ ДОСТУП К ВАШЕМУ ТГ(ИММЕНО ЛИЧНЫМ СООБЩЕНИЯМ)

# Как работает программа:
  1. Берет фотки, названия и высоты с личных сообщений телеграмма
  2. Создает папку для размещения файлов
  3. Создает папку для каждой(ОП, ГТСП, ТСП-ОП) и загружает фотки в неё
  4. (если вы хотите) Распределяет файлы .jps с приемников(может не работать с одним ОП и одной ГТСП). Есть несколько способов распределения:
      1. Распределяет файлы по порядку с одного приемника
         [pink(название приемника), pink, pink, pink, pink]
      2. Распределяет файлы по порядку первый, второй приемник
         [pink, red, pink, red, pink]
      3. Распределяет файлы в соответствии с указаниями номера приемника в тг
         [red: 11(номер приемника), red: 11, pink: 3, red: 11, pink: 3, red: 11]
      4. (работает не стабильно будьте аккуратно) Объединяет 2 и 3 способ распределяет по порядку как обычно, но когда видит номер приемника вставляет по номеру после продолжает со следующего номера
         [red, pink, pink: 3, pink: 3, red, pink, pink: 3] 
  6. Создает XML файл для откоординированных(ОП, ГТСП, ТСП-ОП)
  7. (если вы хотите) Создает папку и копирует основную папку для полетов мавика
     1. Удаляет папки ОП и удаляет строки ОП с XML файла  
# Для пользования
1. Для пользования необходимо TgWsProxy(можно найти на github) и CLIENT APP в телеграмме (как получить hash и api найдите в нейронке, я делал с помощью изменения HOST файла системы).
2. Для управления ENTER пропустить или напишите свое значение; в нужен прокси(yes/no)
3. Возьмите HOST, PORT, SECRET в TgWsProxy
4. Берёт файлы .jps из Новой папки, которая находится в одной папке с создаваемой основной папкой
5. В телеграмме заполнение "ТСП-ОП-341_2 1234 22" или "ОП-43_5 1334" с прикрепленными фотками.
  Объяснение название(ТСП-ОП, ОП, ГТСП)-(номер объекта)-(номер порядковый) (высота) (необязательно: номер приемника)
